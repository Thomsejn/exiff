# Thomsejn's Exif

A simple web app for viewing image metadata, including dimensions, file size, camera model, and GPS location when available.

Live demo: https://thomsejn.github.io/exiff/

## How to use

1. Open the live demo link.
2. Click the Select file button.
3. Choose an image file to view its metadata.
4. The app will show details such as width, height, photo size, camera model, and location when available.

## Features

- Clean and simple interface
- Light and dark theme toggle
- Animated background effects
- Interactive map for GPS location when EXIF data is present
